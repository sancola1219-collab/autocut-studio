# 🎬 自動剪片工作室 · AutoCut Studio

丟影片進來，自動幫你**串接、上字幕、AI 配音、混背景音樂**——還能用**口說的方式**在網頁面板上剪片。
全程在自己電腦上跑，聽打字幕完全離線。

> 為中文創作者打造：字幕自動轉繁體、11 種中文配音（台灣／大陸／粵語）、直式橫式一鍵輸出。

---

## ✨ 兩個工具

### 1. `autocut.py` — 一條龍自動剪片（命令列 / 拖拉）

| 功能 | 說明 |
|---|---|
| 🎙️ 自動上字幕 | Whisper 聽打，自動轉繁體，支援橫式底部字幕與直式大字卡 |
| 🗣️ AI 配音 | 無旁白素材給文字稿即可，11 種聲音，行首標記 `[男]`/`[活潑女]` 可做雙人對話 |
| 🎵 背景音樂 | 人聲出現時音樂自動壓低（sidechain ducking），結尾自動淡出 |
| 🔗 多片串接 | 一次給多支影片自動統一畫質串接，可選淡入淡出轉場 |
| 📐 版式 | 橫式（原尺寸）／直式 9:16（模糊背景＋置中）／兩種都出 |

```bash
python autocut.py 影片.mp4                       # 聽打字幕
python autocut.py 片1.mp4 片2.mp4 片3.mp4          # 多支串接再上字幕
python autocut.py 素材.mp4 --script 稿子.txt        # 文字稿 AI 配音
python autocut.py --list-voices                   # 看所有配音
```

Windows 使用者可直接把影片**拖到 `拖影片到這裡.bat`**，用問答方式完成。

### 2. `voicecut/` — 口說剪片台（很酷的網頁面板）🆕

在瀏覽器面板裡**按住空白鍵講話**就能剪片：

- 「這裡加字幕買一送一」「從這裡開始」→「剪到這裡」「這段加快兩倍」「這裡靜音」
- 語音在本地用 Whisper 辨識（**不花錢、不上傳**），常見命令本地解析
- 剪掉、變速後字幕時間點會自動重新對齊
- 時間軸即時顯示每個操作的標記，可刪除、可微調

```bash
python voicecut/server.py       # 啟動後瀏覽器開 http://127.0.0.1:8765
```

Windows 直接雙擊 `口說剪片台.bat`。

## 🔧 安裝

需要 **Python 3.9+** 與 **ffmpeg**（要在 PATH 裡）。

```bash
pip install -r requirements.txt
```

第一次跑聽打會自動下載 Whisper 模型（medium 約 1.5GB，只有第一次）。
AI 配音使用微軟線上語音，需要網路；聽打字幕則完全離線。

## 📁 目錄

```
autocut.py            一條龍自動剪片
拖影片到這裡.bat        Windows 拖拉入口
口說剪片台.bat          Windows 啟動網頁面板
voicecut/
  server.py           面板後端（Python 內建伺服器，零額外安裝）
  panel.html          面板前端
  parser.py           口說命令解析
  engine.py           剪輯引擎（剪掉/變速/靜音/音量/字幕）
背景音樂/              把 mp3/wav 放這裡
輸出/                 成品出現在這裡
```
